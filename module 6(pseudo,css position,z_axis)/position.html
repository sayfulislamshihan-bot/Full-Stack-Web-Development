CSS Position

  1. Static(one div after another top to bottom)
  2. Relative(Relative change from the current position and will not leave the current spot)
  3. Absolute(will lost it's own position and if no parent is fixed then it will consider the root or display as parent and move from the top of the screen as root but if parent is given then the element will move according to the parent element)
  4. Fixed (Stick to a fixed position of the viewport)
  5. Sticky (become sticky as we scrool the page to to bottom)
